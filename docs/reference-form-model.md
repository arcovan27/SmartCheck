# Referência Operacional

Documento resumido dos fluxos industriais que orientam o SmartCheck.

## EPI
- Entrega e devolução por funcionário.
- Controle de quantidade, CA, responsável e método de confirmação.
- Ficha individual de EPI para auditoria.

## Checklists
- Modelo por equipamento e periodicidade (diário, semanal, mensal).
- Tipos de resposta:
  - OK / Problema / N/A
  - Sim / Não
  - Número
  - Texto
- Regra crítica: problema exige observação e foto.
- Problema pode abrir manutenção corretiva automaticamente.

## Manutenção
- Abertura manual ou automática via checklist.
- Classificação por tipo (preventiva/corretiva), prioridade e status.
- Alertas preventivos por dias, KM e horímetro.

## Biometria
- Estrutura pronta para integração com agente local Windows/.NET.
- Endpoints preparados para iniciar/finalizar cadastro e identificar funcionário.
